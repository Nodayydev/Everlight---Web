📝 YOURUSERNAME helyére a GitHub felhasználóneved!
🔑 Ha jelszót kér, használj GitHub Personal Access Token-t:
   https://github.com/settings/tokens/new


3️⃣ PUSH A GITHUBRA (SSH módszer - biztonságosabb)
