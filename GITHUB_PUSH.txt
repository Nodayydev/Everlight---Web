2️⃣  PUSH A GITHUBRA (HTTPS – egyszerűbb)
────────────────────────────────────────────────────
Futtasd le ezeket a parancsokat a projekt gyökerében:

  git remote add origin https://github.com/YOURUSERNAME/everlight.git
  git branch -M main
  git push -u origin main

📝 YOURUSERNAME helyére írd a saját GitHub felhasználónevedet!
🔑 Ha jelszót kér, használj GitHub Personal Access Token-t:
   https://github.com/settings/tokens/new
   (repo jogosultsággal)


3️⃣  PUSH A GITHUBRA (SSH – biztonságosabb)
────────────────────────────────────────────────────
Ha van SSH kulcsod beállítva:

  git remote add origin git@github.com:YOURUSERNAME/everlight.git
  git branch -M main
  git push -u origin main


4️⃣  JÖVŐBENI MÓDOSÍTÁSOK PUSH-OLÁSA
────────────────────────────────────
Minden módosítás után:

  git add .
  git commit -m "Rövid leírás a módosításról"
  git push origin main

(Render automatikusan újra deploy-ol, ha be van kötve a repo.)


5️⃣  RENDER DEPLOYMENT
────────────────────────────────────
📍 https://render.com
1. Sign up GitHub fiókkal
2. New → Web Service → válaszd az „everlight” repo-t
3. Build Command: npm install
4. Start Command: npm start
5. Environment Variables (legalább):
   - JWT_SECRET = hosszú, véletlenszerű titok
   - DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASSWORD
     (lásd MYSQL-SETUP.md)

✅ KÉSZ! Az app fut: https://everlight-xxxxx.onrender.com
